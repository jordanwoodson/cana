# Cana 3.2.2-cana.8

This release makes Cana's app management easier to scan and safer to act on. The compact main list shows clear profile and app-state information, live counts, quicker filters and a selection bar that recommends the right action for the selected apps.

- Confirmations name the exact action, profile and risks. Verified successes appear in a snackbar with Undo when available; failures remain visible for review. History offers Undo for completed batches that do not conflict with later changes.
- App detail, Privacy, Components, Device settings, Compare, Presets, Logs and Settings have clearer controls and state labels. The Privacy dashboard now shows app names and live enforcement alongside saved restrictions.
- First run guides the risk acknowledgement, Shizuku setup and profile choice. Wallpaper colours are optional and off by default; semantic risk colours stay consistent across themes.
- Touch targets, content descriptions, enlarged text and RTL layout were reviewed on the Android 15 emulator, along with light/dark, Personal/Work and wallpaper-colour combinations.

Install over the previous signed Cana release, or update through Obtainium from this repository. The application ID and signing identity are unchanged. Version code advances from 231 to 232.

Validation: 225 JVM tests passed, both debug and signed release builds passed, and debug/release lint had zero errors (708 warnings and one hint per variant, chiefly untranslated strings). Affected UI/device tests passed on the Android 15 Personal and Work emulator, including Work-profile Undo, populated Privacy dashboard cards and the Shizuku authorization lifecycle. The signed APK upgraded over the checksum-verified published `.7` APK in place on the emulator, retained its first-install timestamp, and rendered the first-run screen after AOT compilation. Component mutation/Undo still needs a root-backed Shizuku device for runtime verification; this emulator cannot execute that operation. The first-run profile choice applies immediately but currently returns to Personal on a later launch.

Signing certificate SHA-256: `748e751a9dd9240f9e8cc7cd7f7218dd1541e6abaa09603d282284062639e345`, matching the published `.7` APK.

The release assets include the signed APK, `SHA256SUMS.txt` and a build attestation. The [UX handoff report](https://github.com/jordanwoodson/cana/blob/3.2.2-cana.8/docs/ux/final-report.md) contains the full U1–U32 results and screenshot comparisons.
