# Cana 3.2.2-cana.4

Cana now keeps selected apps and profile context visible throughout reviewed actions, tracks long-running work across navigation and recreation, and provides clearer privacy and recovery tools.

- Persistent selection shows hidden selections and reviews every requested target before execution. Grouped filters, named views, and saved package collections make repeat work easier.
- App details separate Overview, Privacy, and Components. Android App info opens the selected profile; read-only profile comparison shows installation differences side by side. Detail tabs remain usable with enlarged text.
- Durable batches show progress and support stopping between items. Interrupted work is retained without automatic replay. Unknown installer outcomes remain pending until verified, and conflicting retries are blocked.
- Privacy controls include a dashboard, selected-permission changes, readable live values, identity-bound review, shared-UID consent, and safe removal of stale saved restrictions. Exact Undo and preset capture preserve recorded intent.
- History groups results and recovery status, retains unresolved operations, and archives completed records for recovery export. Backup includes portable preferences, presets, and saved views while excluding operational state.
- Preset imports show changes before saving; applying a preset reviews missing targets, profiles, and shared effects. App inventories refresh after mutations and use cached metadata while updates run in the background.
- Startup hidden-API initialization is serialized, Android app-op default output is parsed correctly, and component actions share authentication and batch handling. Obsolete UI/resources were removed, logs are bounded, custom list URLs require validated Save, and CI coverage and documentation were expanded.

Reapplying saved restrictions after reboot depends on Shizuku availability and Android scheduling. New strings use English fallback where translations are unavailable.
