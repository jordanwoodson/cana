# Cana 3.2.2-cana.7

Shizuku setup now handles repeat taps, denial, retry, service reconnects and activity recreation without retaining old UI callbacks. Setup stays open after denial, shows actionable status and timeout messages, and remains usable with larger text.

- App rows and Overview show the size of active base/split APK files and, for updated system apps, the included update APK size. Unreadable sizes stay unavailable; these figures exclude app data and do not predict space freed.
- Tracker scans reject unreadable splits and malformed or oversized DEX files instead of reporting a false clean result. Cached counts follow both the app version and APK file metadata. Source changes discard stale scans; cancelling and restarting a batch preserves the new scan's progress.
- The tracker-source editor waits for the saved source before allowing changes and preserves an edited URL through recreation. Batch results distinguish successful scans from failures.
- Live operations no longer appear as abandoned recovery work. Separate reconciliation jobs own their cancellation, package inventory lookup is faster, and external links report missing handlers.
- CI signing properties are escaped without interpolating secrets into shell commands.

Broader tracker sources were compared with the bundled Exodus signatures. Confirmed Exodus data remains the default; the additional App Manager/ETIP entries need their investigative status and provenance preserved before integration. No new tracker dataset is bundled. See the [source comparison](https://github.com/jordanwoodson/cana/blob/3.2.2-cana.7/docs/superpowers/plans/2026-09-30-tracker-sources.md).

Install over the existing Cana release, or update through Obtainium using this repository. Application id remains `io.github.jordanwoodson.cana`; version code advances from 230 to 231. The existing signing identity is preserved.

The implementation passed 197 JVM tests and 27 distinct API 35 emulator regressions, including authorization and activity recreation checks. Manual acceptance also exercised real shell-backed Shizuku denial, retry and grant, large text, APK size labels and a scan of Cana's own debug APK. Debug/release builds, both lint variants and the documentation build passed. Lint retains 493 warnings and one hint per variant, with zero errors. The versioned release build also passes all 197 JVM tests; the emulator acceptance preceded the version-only change from 230 to 231.

Physical phones, OEM images and root-backed Shizuku were not tested. Tracker matches identify bundled code, not runtime tracking; native libraries, downloaded code and network traffic are outside the static scanner's coverage.
