# Get Cana

**Do more. Because you can.**

Download the APK from [Cana's latest GitHub release](https://github.com/jordanwoodson/cana/releases/latest).

## Updates with Obtainium

Add this source URL in [Obtainium](https://github.com/ImranR98/Obtainium):

```text
https://github.com/jordanwoodson/cana
```

Cana's application ID is `io.github.jordanwoodson.cana`, so it can be installed
alongside [Canta](https://github.com/samolego/Canta). Canta's store listings install
the original app.

## Verify the APK

Cana releases use this SHA-256 signing certificate fingerprint:

```text
74:8E:75:1A:9D:D9:24:0F:9E:8C:C7:CD:7F:72:18:DD:15:41:E6:AB:AA:09:60:3D:28:22:84:06:26:39:E3:45
```

Continue with the [setup guide](/install) to start Shizuku and choose a profile.
